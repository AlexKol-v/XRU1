## 3. Известные дефекты, не блокирующие приёмку

- **`agent radius 35.0`** в логе сборки навмеша против `AgentRadius=45` в
  `DefaultEngine.ini`: навмеш строится под более узкого агента, чем реальная
  капсула. Узкие проходы между контейнерами AI считает проходимыми. Радиус на
  акторе навмеша не правится — только Project Settings → Navigation System →
  Supported Agents.

## 4. Проверить починку старта боя (2026-08-04)

Старт боя теперь ждёт готовности навигации (`08_AI.md` §3.13.1). Подтвердить:

- [ ] В логе есть `[GameMode] Навигация готова через X с — стартую бой`.
- [ ] **Нет** ни одной строки `[Encounter] ... поставлен без подтверждения
      навмешем` — все группы встали на заданные точки, а не фолбэком.
- [ ] Нет `[GameMode] Навигация не готова за N с` (это таймаут: значит навмеш
      карты действительно не строится, и чинить надо карту).
- [ ] Часовые у заряда стоят у заряда с первого кадра боя, а не «примерно там».
- [ ] Пауза перед первым ходом терпимая. Если нет — это аргумент за экран
      загрузки (`04_ROADMAP.md`), а не за отключение ожидания.
