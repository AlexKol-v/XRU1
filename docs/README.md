## Текущий срез — 2026-08-04

Свежее: обучение собрано целиком (секции A–D, 26 шагов с озвучкой и подсказками),
фронтенд замкнут (меню → сложность → интро → хаб → брифинг → бой → результат),
камера переведена на модель XCOM 2, презентация выстрела доведена доворотом и
kill-cam. Дизайнерские Data Assets сведены в одно дерево
`/Game/XRU1Game/Data/<Core|Units|AI|Missions>` (правило — `06_CONVENTIONS.md` §3).

Закрыто и не ведётся как активный план:

- тактическое ядро, AP, перемещение, общая маршрутизация и резервация мест;
- физическая система Half/Full cover, LOS, flanking и огневые позиции;
- анимационный блок: locomotion, прижатие к укрытию, peek/StepOut, выстрел по
  `FireCommit`, HitReact, единственная death-последовательность и возврат в anchor;
- разные модели оружия у классов: AssaultRifle, Sniper, SMG и LMG;
- функциональное ядро боевого HUD и весь цикл экранов меню/хаба;
- звуковой слой: микшер, профили юнитов, музыка, озвучка обучения и хаба;
- камера (модель XCOM 2) и кадр выстрела.

Активная работа:

1. **Приёмка** ([agents/ACCEPTANCE_CHECKS.md](agents/ACCEPTANCE_CHECKS.md)) —
   единственный файл со списком «сделано, но не проверено прогоном». Первым
   идёт AI: три боя на Hard и различимость сложностей.
2. Рефакторинг документации и коммит накопленного
   ([agents/BRIEF_DocsRefactor.md](agents/BRIEF_DocsRefactor.md),
   [agents/BRIEF_CommitAudit.md](agents/BRIEF_CommitAudit.md)). Порядок: сначала
   коммит, потом доки — иначе рефакторинг добавит сотню изменений в и без того
   большую кучу.
3. Остаток HUD ([09_UI_HUD.md](09_UI_HUD.md) §4): названия и заряды на кнопках
   способностей (сейчас у всех классов подпись «классовая способность»),
   причина недоступного действия у кнопки, секционный HP в карточке отряда,
   проверка вёрстки в разрешениях и контраста иконок.

Закрыто целиком: **обучение** (расставлено, проходится A1→D3 — `11`, `12`),
**туман войны** (слой правил и визуальное затемнение с тремя состояниями GDD
§5.9 — `10`), **способности классов** (числа и поведение приняты игроком),
**итоговая миссия** (расстановка, цели, реплики — проходится от начала до конца,
`16`), **AI** (план `08_AI.md` §4 выполнен целиком: лестница фолбэков, память
контактов, риск маршрута, резервации, профили сложности, 7 автотестов — §4.8;
осталась приёмка прогоном).

Отложено, пока не блокирует демо:

- анимация доворота корпуса и Aim Offset;
- IK/Control Rig для автоматической укладки второй руки на цевьё/приклад;
- профиль тумана в Unreal Insights (замер есть только по журналу).

## Как работать с документацией

1. Перед изменением механики сверить `01_GDD.md` и текущий пункт
   `04_ROADMAP.md`.
2. Перед C++-работой открыть `03_CODE_OVERVIEW.md`; перед AI/UI — соответственно
   `08_AI.md` или `09_UI_HUD.md`.
3. После реализации обновлять только документ своей темы и `04_ROADMAP.md`.
4. Не создавать новый глобальный audit/checklist-файл для единичного бага:
   добавить короткую задачу в ROADMAP, исправить, проверить и удалить задачу.
5. История миграции из донора остаётся вне `docs/` — в
   [../MIGRATION_NOTES.md](../MIGRATION_NOTES.md).

## Быстрый старт на второй машине

```powershell
git pull
git lfs pull
.\Build-XRU1.ps1
```

Редактор перед сборкой должен быть закрыт. Пути к проекту и UE не хардкодить:
`Build-XRU1.ps1` находит UE 5.7 через реестр. После изменения C++ обновить
локальный индекс codebase-memory для корня проекта.
