# XRU1 «Тихий узел» — документация

Курсовой прототип пошаговой тактики в духе XCOM 2 на UE 5.7: укрытия, очки
действий, наблюдение, отряд из четырёх классов. Демо — меню → хаб → обучение →
боевая миссия → финальный экран.

> **Источник истины — код, ассеты и git.** Эти документы объясняют, **как
> задумано и почему принято именно так**. При расхождении с кодом прав код;
> расхождение чинится в доке, а не в коде «под доку».

## Состояние проекта на 2026-08-05

**Проект собран целиком и проходится от начала до конца.** Закрыто и как активная
работа не ведётся:

- тактическое ядро: ходы, AP, перемещение, общая маршрутизация, резервация мест;
- физическая система Half/Full cover, линия огня, фланг, огневые позиции;
- анимации: locomotion, прижатие к укрытию, peek/StepOut, выстрел по `FireCommit`,
  HitReact, единственная death-последовательность, возврат в anchor;
- четыре класса с разным оружием и своими способностями (числа приняты);
- боевой HUD и весь цикл экранов: меню → сложность → интро → хаб → брифинг → бой →
  результат;
- туман войны: слой правил и визуальное затемнение с тремя состояниями;
- камера по модели XCOM 2 и кадр выстрела;
- звук: микшер, профили юнитов, музыка, озвучка обучения и хаба; слой субтитров;
- обучение (26 шагов A1–D3 с озвучкой и подсказками) и итоговая миссия «Узел-7»
  (расстановка энкаунтерами, цели, таблица реплик, подкрепления);
- AI: лестница фолбэков, память контактов, риск маршрута, резервации, профили
  сложности, 7 автотестов;
- локализация: цель `Game` собрана и скомпилирована, 2044 слова, `en` переведён
  целиком; текст ассетов приведён к локализуемому виду утилитой
  (`03_ARCHITECTURE.md` §13).

**Что осталось** — целиком в [04_BACKLOG.md](04_BACKLOG.md), кратко:

| Приоритет | Суть |
|---|---|
| **P0** | экран загрузки миссии |
| **P1** | остаток HUD (названия способностей на кнопках, причина недоступного действия, секционный HP в карточке); меш бомбы; субтитры к остальной озвучке; functional-тесты тумана |
| **P2** | Aim Offset, IK второй руки, свои Niagara-системы, Foliage/PCG, профиль тумана в Insights |
| **Приёмка** | ~90 проверок: AI (три боя на Hard, различимость сложностей), матрицы обучения и миссии, туман, жизненный цикл и retry. Всё это **написано и собрано**, но не подтверждено прогоном |

**Что можно добавить** (не обязательства, а осознанно отложенные идеи с
обоснованием) — [04_BACKLOG.md §5](04_BACKLOG.md): power nodes с добавкой к
таймеру, подкрепление на отходе, три хода на эвакуацию вместо мгновенного
поражения по таймеру, отдельная поза «стрельба сидя из-за укрытия». Там же §6 —
что **снято с плана и почему**, чтобы никто не «доделал» это по старой памяти.

## Как работать с документацией

1. Перед задачей: [04_BACKLOG.md](04_BACKLOG.md) — что открыто, и
   [01_GDD.md](01_GDD.md) — какие правила. Меняешь механику вопреки GDD — сначала
   правь GDD.
2. Перед C++-работой: [03_ARCHITECTURE.md](03_ARCHITECTURE.md); по AI —
   [08_AI.md](08_AI.md). Там же ловушки движка, каждая из которых стоила времени.
3. После реализации: закрой пункт беклога либо **переведи его в «Приёмку»** — если
   код готов, но прогона не было, это не «сделано».
4. Не заводить новый audit/checklist-файл ради единичного бага: короткая задача в
   беклоге → исправить → проверить → удалить задачу.
5. История миграции из донора — вне `docs/`, в [../MIGRATION_NOTES.md](../MIGRATION_NOTES.md).
   Журналы прошлых сессий не восстанавливать: они целиком в `git log`.

## Быстрый старт на второй машине

```powershell
git pull
git lfs pull
.\Build-XRU1.ps1
```

Редактор перед сборкой должен быть закрыт; пути не хардкодить — `Build-XRU1.ps1`
находит UE 5.7 через реестр. Подробности — [05_WORKFLOW.md](05_WORKFLOW.md) §1.
