## Текущий срез — 2026-07-29

Закрыто и не ведётся как активный план:

- тактическое ядро, AP, перемещение, общая маршрутизация и резервация мест;
- физическая система Half/Full cover, LOS, flanking и огневые позиции;
- анимационный блок: locomotion, прижатие к укрытию, peek/StepOut, выстрел по
  `FireCommit`, HitReact, единственная death-последовательность и возврат в anchor;
- разные модели оружия у классов: AssaultRifle, Sniper, SMG и LMG;
- функциональное ядро боевого HUD.

Активная работа:

1. Собрать Tutorial и Mission01 как два сценария одной persistent-карты
   `/Game/US_Military/Levels/Showreel_Scene`.
2. Полноценно настроить и отладить AI на готовой системе укрытий.
3. Реализовать туман войны без утечек через HUD/camera/targeting.
4. Точнее настроить способности классов и доделать HUD/экраны.

Отложено, пока не блокирует обучение:

- переработка ракурсов и общего поведения камеры;
- IK/Control Rig для автоматической укладки второй руки на цевьё/приклад;
- дополнительная косметическая полировка уже принятой системы анимаций.

## Как работать с документацией

1. Перед изменением механики сверить `01_GDD.md` и текущий пункт
   `04_ROADMAP.md`.
2. Перед C++-работой открыть `03_CODE_OVERVIEW.md`; перед AI/UI — соответственно
   `08_AI.md` или `09_UI_HUD.md`.
3. После реализации обновлять только документ своей темы и `04_ROADMAP.md`.
4. Не создавать новый глобальный audit/checklist-файл для единичного бага:
   добавить короткую задачу в ROADMAP, исправить, проверить и удалить задачу.
5. История миграции из донора остаётся вне `docs/` — в
   [../MIGRATION_NOTES.md](../MIGRATION_NOTES.md).

## Быстрый старт на второй машине

```powershell
git pull
git lfs pull
.\Build-XRU1.ps1
```

Редактор перед сборкой должен быть закрыт. Пути к проекту и UE не хардкодить:
`Build-XRU1.ps1` находит UE 5.7 через реестр. После изменения C++ обновить
локальный индекс codebase-memory для корня проекта.
